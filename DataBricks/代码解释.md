## 1️⃣ `case when Data Type = 'X' and Related Values = 'M3'`

这一句**不是在选 SQL 列**，而是在 **选“配置行”**。

它的含义是：

> ✅ 只处理 `screen_file_mapping` 中
>
> - Data Type = 'X'
> - Related Values = 'M3'  
>    的那些行

⚠️ **关键点**  
👉 这里筛选的是 **元数据行（metadata rows）**  
👉 不是数据表的列

---

## 2️⃣ `PADP Column` 在这里到底是什么？

`PADP Column` **不是字段值**，而是：

> ✅ **字段名本身（column name）**

举例（假设 `screen_file_mapping` 中有这些行）：

| PADP Table  | PADP Column | Data Type | Related Values |
| ----------- | ----------- | --------- | -------------- |
| IMG_SUPPORT | wire_gauge  | X         | M3             |
| IMG_SUPPORT | wire_tip    | X         | M3             |
| IMG_SUPPORT | colour      | X         | M1             |

那么：

- `M3` 这一组里  
   👉 `PADP Column` = `wire_gauge`, `wire_tip`
- `colour` 会被 **完全忽略**
